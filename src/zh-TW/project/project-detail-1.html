專案介紹

一趟完美的旅遊背後是需要耗費很多研究時間，該如何幫助用戶在繁雜的資訊中，仍可以輕鬆選購行程團是本次改版的目標。

因專案時程有限，額外與組員利用下班時間進行詳細的UX研究，找出解決痛點的解方，增加用戶黏著度。

負責項目

介面設計、流程優化、研究訪談、易用性測試

團隊成員

1位專案 / 2位UIUX設計師 / 1位前端工程師 / 1位後端工程師

01.我的貢獻

專案中我主要的任務是輔助研究調查及分擔部分內頁設計，經過研究提出喜好度填寫機制，提升首頁推出的內容可以更精準地抓到用戶的需求，接著結合比較清單功能輕鬆分析行程優缺點，增加閱讀便利性，並優化後台的維護模式，減少人員的上稿時間。

02.面臨的挑戰

旅遊介紹資訊往往冗長且繁多，需在不減少內容的條件下完成簡潔的版面配置，其中結合動態功能，旨在兼顧美感和實用性，找到兩者之間的平衡是非常重要的關鍵要素。 由於客戶資金有限，無法採納所有設計方案，加上時程緊迫，研究的時間也不充裕，因此需要對部分項目進行取捨，以完成當前階段必須執行的基本項目。

03.結果與影響

上線兩個月網站新增使用者人數從1564人提升至4869人，活躍用戶數量約為3000多人。後台維護人員上架時程減少50%左右的工時，加速工作效率。

首頁

舊版的整體色系風格較為沈重，此次改版的方向是採用更貼近品牌形象的白色搭配金色，呈現典雅精緻的氛圍，視覺上既簡潔俐落又不顯單調。功能部分新增最大與最小的旅遊天數，提供用戶更多元的篩選條件，點選關鍵字搜尋會出現熱門推薦以及歷史搜尋紀錄，簡化搜尋框資訊。

行程頁

原先把所有行程特色資訊與出團表綜合於一頁，資訊過於繁雜無法聚焦於出團列表，改版後將行程內容放置詳細頁，讓用戶一進到頁面就可以快速挑選行程。考量區分國家篩選及進階搜尋的結果，加上列表資訊些微不同，一種以直式編排另一種以橫式編排。

旅遊行程規劃的雙裝置協作模式

研調後發現旅遊行程規劃已形成「電腦主導前期規劃、手機主導後期執行」的雙裝置協作模式，由於旅行行程較為冗長且資訊量大，使用者在規劃初期多以電腦版進行查找與比較，方便進行詳細的方案確認。完成初步規劃後，使用者將資訊分享給親友，讓他們了解行程概況。因此單純接收資訊的親友則多以手機瀏覽為主，快速掌握行程重點與安排。

  • 電腦版需強調資訊的完整呈現與清晰的比較流程，協助使用者做出決策。

  • 手機版則以簡潔易讀為主，重點式資訊呈現，方便接收者快速了解大致行程與安排，避免過度操作造成閱讀負擔。

根據注意力熱點分析結果，價格為用戶最關注的資訊，故優先調整至版面首位以提升可見性。

因應版面寬度限制，月份顯示方式調整為單月切換，避免資訊擁擠導致閱讀困難。

當頁籤改為下拉選單呈現時，欄位文字將隨使用者點擊的標題動態更新為對應名稱，讓使用者清楚辨識目前所在的內容區塊。

03

購物車

簡化下單流程，將所有填寫欄位集中於第一步驟。右側釘選重要資訊，方便用戶隨時下訂。考慮到用戶反饋，新增常用旅客功能，讓會員在購物車下單時可快速帶入顧客資訊，加速訂購流程。根據易用性測試反饋，優化資料確認步驟，支持即時修正旅客資訊，考量程式撰寫規則，採用跳框編輯方式。

第二步驟

解決操作步驟與頁面冗長問題的設計對策

手機版需克服因簡化下單流程所導致的頁面過長問題，以及右側釘選項目在小螢幕上的呈現限制，為避免使用者在長頁中迷失，導致操作效率下降，須優化內容結構與互動方式。整體目標為在保持資訊完整的前提下，提供精簡、清晰且高效的下單體驗，特別針對行動裝置使用者優化操作流程與介面呈現。

右側釘選項目可改為下方浮動式工具列，訂單資訊採取收合功能，次要資訊不佔據可視空間，讓使用者能更專注於操作流程，以及關鍵價格資訊與「確認送出」按鈕上，提升行動裝置下的操作效率與下單體驗。

考量操作彈性，欄位預設為收合狀態，使用者可依自身需求選擇展開單一欄位或一次展開全部，以利後續資訊填寫。

會員中心

首次實戰中，我們將完整的UX方法引入公司專案，但面臨客戶預算不足和公司既有時程無法調配等挑戰，導致上線版本未能如預期達成目標，讓人感到可惜。然而，內部人員達成共識，私下進行學習，並繼續推進其他目標。由於旅行主題容易找到受測者，我們順利執行了易用性測試，透過用戶的反饋發現設計盲點。隨後，與組員共同進行腦力激盪，找出解決方案。親自體驗迭代過程，使我們能夠不斷完善網站，這次深入的UX研究經驗讓我收穫良多。

訂定未來藍圖

AI智能技術的引用是未來重點發展的目標，如何透過智能技術減少更多人力成本，並且帶給用戶更多友善的體驗，像是開發智慧導遊量身打造專屬旅客的行程，打破跟團旅遊的刻板印象，讓旅客不需要辛苦做功課，也能享有自由行的好處。
優化行動商務的作業流程與導入AI進行準確、優質服務體驗，將是打開旅遊業復甦的利器。
